# 簡報背景研究筆記

拆解兩支「用 AI 做簡報」的影片與三份對照文件，整理成一套可以照著做的背景圖方法。

線上閱讀：https://yazelin.github.io/slide-background-research/

## 內容

- 判準：什麼樣的圖能當簡報背景（留白、單一視覺中心、可控對比、敘事張力）
- 方法一　尺度失衡：把主體放進不屬於它的宏大情境
- 方法二　光：在平淡畫面加一個發光元素製造視覺中心
- 提示詞的四段結構，附中英提示詞塊對照表
- 靜態圖轉動態背景的運鏡公式與無限循環做法
- 手上已有醜圖的三步搶救法
- 另一條路：用 HTML 與 WebGL 把背景畫成程式

## 做法

兩支影片都沒有字幕軌，逐字稿是本機跑 whisper large-v3-turbo 轉出來的；文件版的內容照原文整理。兩邊對得起來的部分才寫進筆記。所有提示詞我都沒有實測過，這一點寫在筆記的第 11 節。

## 出處

方法與案例的著作權屬於原作者「大师的AI小灶」，來源連結列在筆記第 12 節。這個 repo 只有整理與分析。
